# Event-HUB 🚀

**Event-HUB** is a comprehensive, all-in-one event management ecosystem designed to eliminate the friction of organizing, participating, and judging tech events and hackathons. Built for Code Carnival 3.0 at Atmiya University!

## 🎯 The Problem
Managing college tech events requires juggling multiple disjointed platforms for registrations, communication, and judging. Organizers waste time on logistics instead of focusing on event quality.

## 💡 Our Solution
A dynamic **4-Tier Role System** where each user gets a custom dashboard tailored to their tasks:
- **Host**: Creates events, manages websites, and oversees real-time analytics.
- **Participant**: Registers via QR code, forms teams, and submits projects.
- **Judge**: Scores submissions live, instantly updating the central leaderboard.
- **Attender**: Views live schedules, announcements, and leaderboards.

## 🛠 Tech Stack
- **Frontend**: React 19, Vite, Tailwind CSS v4, Zod
- **Backend & Auth**: Supabase
- **Routing**: TanStack Router (File-based routing)
- **Deployment**: Cloudflare Pages

## 💻 Local Setup
To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/kishan-ict/Event-HUB.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
